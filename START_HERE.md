## 🎓 Key Concepts

### Domain Mapping
Your project maps generic terms to your domain:
- **Catalog** = Volunteer Opportunities
- **Entry** = Individual volunteer event
- **Collection** = Volunteer's basket of interested events
- **Commit** = Confirming participation

### 10% Feature
**Map Integration** - Display events on a map with proximity-based filtering using Haversine distance calculation

### Tech Stack
- **Backend:** Spring Boot (Java)
- **Frontend:** Angular (TypeScript)
- **Database:** PostgreSQL
- **Mapping:** LeafletJS
