## 📋 GitHub Commit Strategy

### Commits Made on Behalf of Partner

When making commits that represent partner's contributions, use one of these formats:

**Option 1: Include in commit message**
```
FEAT(auth): implement user authentication [by Partner Name]
```

**Option 2: Use Co-authored-by (GitHub recognized)**
```
FEAT(auth): implement user authentication

Co-authored-by: Partner Name <partner.email@example.com>
```

**Option 3: Document in commit description**
```
FEAT(auth): implement user authentication

This commit includes contributions from:
- Partner Name: Code review and feedback
```
